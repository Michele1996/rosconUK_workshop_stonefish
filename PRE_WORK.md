# Pre-work Checklist

Required before attending:

- [ ] Ubuntu 22.04 available.
- [ ] ROS 2 Humble works.
- [ ] Stonefish starts.
- [ ] `ros2 pkg prefix stonefish_ros2` works.
- [ ] Workshop repository builds with `colcon build --symlink-install`.
- [ ] `ros2 launch roscon_stonefish_workshop blueboat_workshop.launch.py` opens.
- [ ] `ros2 topic list` shows the BlueBoat simulator interfaces.

Not required yet:

- [ ] BlueROV2 final environment — supplied later.
- [ ] Reference reconstruction dataset — supplied later.
- [ ] COLMAP/GLOMAP — optional pre-install.

Do not spend hours debugging optional reconstruction software before ROSCon.
The priority is a working ROS 2 + Stonefish installation.
