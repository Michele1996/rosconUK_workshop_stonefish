# Reconstruction Resources

This directory is intentionally lightweight in the participant-preparation
release.

Before the workshop, the organisers will add:

- the image-export helper used with the final ROS bag layout;
- a known-good reference image set;
- the tested COLMAP/GLOMAP command sequence;
- example expected output.

Participants do **not** need the reconstruction pipeline working in advance.
The required pre-work is ROS 2 + Stonefish.
